# STREET SURVIVAL β0.5 Game Map版

## 追加機能

- 現実地図 / ゲーム地図 切替
- ゲームマップにアイコン表示
  - 🟢 あなた
  - ☕ HP CHARGE
  - 🍜 HP CHARGE
  - 🎵 お宿 Onn / LIVE SAFE
  - 👹 RAID BOSS
  - 🎯 MISSION
- ランナー接近演出
  - 30m 👀 気配
  - 20m ⚠ 接近
  - 10m 🚨 危険
  - 7m ⚔ 接触
- ハンター側：15m以内で気配アラート
- SAFE / HP CHARGE ZONE中はバイブ停止
- HPチャージ：5秒ごとに+2HP
- HP 初期100 / 最大300 / 最低10
- 1分でハンター / ランナー交代

## 更新方法

- index.html
