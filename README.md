# STREET SURVIVAL β6.2 Event Sounds HUD

## 追加内容

イベントごとに専用サウンドを追加しました。

- 🛡 SAFE：明るい回復音
- 👹 BOSS：低い警告音＋ノイズ
- 🎯 MISSION：ピピッという指令音
- 🎵 LIVE：ファンファーレ風
- 🔥 FINAL：サイレン風＋低音
- 🏆 GAME END：勝利・終了音
- 🔊 FX TEST：通常テスト音

## メニュー内テスト

MENUを開くと、各イベント音を個別に試せます。

- SAFE音
- BOSS音
- MISSION音
- LIVE音
- FINAL音
- END音

## 注意

iPhoneではバイブは使えない場合があります。
β6.2は、音・光・レーダー波紋・画面演出でイベントを伝える設計です。
