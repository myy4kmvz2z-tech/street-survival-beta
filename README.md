# STREET SURVIVAL β0.4 Vibration Alert版

## 追加機能

- ハンター接近アラート
- ハンター側：ランナーが15m以内にいると一定間隔でバイブ
- ランナー側：ハンターが近づくほどバイブ間隔が短くなる
  - 30m以内：気配
  - 20m以内：接近
  - 10m以内：危険
  - 7m以内：接触 / HP吸収
- iPhone Safariでバイブ非対応の場合は画面表示で代用
- SAFE / HP CHARGE ZONE中はバイブ停止
- HP 初期100 / 最大300 / 最低10
- HPチャージ：5秒ごとに+2HP
- 1分でハンター / ランナー交代

## 更新方法

GitHubのトップに以下4ファイルを上書きアップロードしてください。

- index.html
- style.css
- app.js
- README.md

GitHub PagesのURLをiPhone Safariで開き、位置情報を許可してください。
