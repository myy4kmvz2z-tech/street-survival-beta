# STREET SURVIVAL β1.1 Home Renewal

## β1.1 目的

3秒で自分の状況が分かるホーム画面へ完全リニューアル。

## 追加・変更

- 超巨大ステータスを最上部に配置
  - RUNNER / HUNTER / SAFE / BOSS / FINAL
- HP・街状況・参加人数・残り時間を上部固定のミニ情報バー化
- 地図を中央に配置
- SAFE / BOSS / FINALを全画面演出
- 運営モードを折りたたみ式に変更
- RADIOをコンパクトなテロップに変更
- スクロール量を大幅削減
- β1.0 Stage1のゲーム機能は継続

## 更新方法

GitHubのトップに以下4ファイルを上書きアップロードしてください。

- index.html
- style.css
- app.js
- README.md
