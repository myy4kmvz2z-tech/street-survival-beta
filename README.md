# STREET SURVIVAL β2.0 Rebuild

## コンセプト

3秒で状況が分かる。
スクロールほぼゼロ。
巨大ステータスとゲーム地図を中心にした、街RPG端末。

## 主な変更

- ホーム画面を完全再設計
- 最上部に巨大ステータス
  - RUNNER
  - HUNTER
  - SAFE
  - BOSS
  - FINAL
- HP・参加人数・街状況・残り時間を巨大ステータス内に統合
- 地図を中央に大きく配置
- ゲーム地図を標準表示
- 現実地図はボタンで切替
- 操作ボタンは3つだけ
  - GPS
  - HUNTER/RUNNER切替
  - TEST
- 運営モードは折りたたみ
- SAFE / BOSS / FINALは全画面演出
- RADIOは下部テロップ化
