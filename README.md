# STREET SURVIVAL β5.0 Tactical HUD

## コンセプト

街を歩く人が、スマホを見た瞬間に自分がRPGの主人公になったと感じるUI。

## β5.0 変更点

- Tactical HUD風ホーム画面
- 上部に巨大ステータス
- 中央に丸型レーダー
- 自分は常に中央
- HP / SAFE / LIVE / 本町 / 新町 / BOSS / MISSION / HUNTER をレーダー表示
- SAFE時は緑波動
- BOSS時はWARNING演出
- FINAL時は赤いHUD演出
- 下部は RADIO速報
- 操作は GPS / ACTION / MENU の3つ
- MENU内に運営・ログ・詳細を格納
- 地図モードは RADAR / GAME / REAL 切替
