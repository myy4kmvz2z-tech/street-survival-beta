# STREET SURVIVAL β0.6 6時間イベント仕様

## β0.6 変更点

- ゲーム時間：6時間想定
- 途中参加・途中退出OK
- ランナーは捕まるまでランナー
- ハンターは最大10分
- HP0になったら即役割交代
  - ランナー → ハンター
  - ハンター → ランナー
- 役割交代後、5秒間無敵
- HP 初期100 / 最大300 / 最低0
- HPチャージゾーン：5秒ごとに+2HP
- SAFE / HP CHARGE ZONE中は戦闘停止
- ハンター側：ランナー15m以内で一定バイブ
- ランナー側：30m / 20m / 10m / 7mで段階アラート
- 現実地図 / ゲーム地図 切替

## 7/5 運用イメージ

6時間の街歩きイベントとして運用。
参加者は好きなタイミングで参加・休憩・復帰できる。
飲食店やお宿 OnnはSAFE / HP CHARGE ZONEとして設定。
