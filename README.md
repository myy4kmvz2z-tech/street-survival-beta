# STREET SURVIVAL β版

街を使った個人勝ち残りゲームのプロトタイプです。

## 入っている機能

- プレイヤーHP 100
- 他プレイヤーが半径10m以内に入るとHP吸収
- 配信ONで吸収速度 +10%、ポイント +5%
- 配信ONのプレイヤーはLIVE表示
- 店舗スポットでQR風チェックイン
- カフェ：30秒バリア
- ハンバーガー屋：HP+20
- ラーメン屋：吸収ブースト
- ライブ会場：レアポイント
- 運営ログ表示

## 起動方法

このフォルダを開いて、`index.html` をブラウザで開くだけです。

スマホで試す場合は、GitHub Pages / Netlify / Vercel などにアップしてください。
