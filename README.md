# STREET SURVIVAL β10.1 No Global Flash

## 修正内容

画面全体が点滅する問題を修正しました。

## 変更点

- body全体にかかる点滅演出を停止
- ALERT / 通知 / DANGER / FINAL の全体フラッシュを無効化
- 必要な反応はステータスパネルやレーダーだけに限定
- Firebase / 通知 / GPS / SAFE / BOSS / LIVE / RADIO は維持

## アップロードするファイル

`street-survival-beta` に以下を上書きしてください。

- index.html
- app.js
- style.css
- sw.js
- manifest.webmanifest
- icon-192.png
- icon-512.png

`firebase-config.js` は今動いているものを残してもOKです。
